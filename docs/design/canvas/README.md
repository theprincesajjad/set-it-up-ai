# Design canvas (source of truth for v2.1)

These are the artboards from the design canvas (claude.ai artifact "Local Loyalty — app design").
Each `.dc.html` file is one screen: plain HTML with inline styles, so exact sizes, colours,
spacing and copy can be read straight from the markup. `/_blob/<id>` images are the category
objects in `packages/design-tokens/assets/categories/` (coffee, bakery, eat, shops, beauty,
repair, services, top).

| File | Screen |
| --- | --- |
| Main.dc.html | Explore map (Corner-style), first tab |
| Discover.dc.html | Discover feed (Hypelist-style hero, chips, near-you map card, rows) |
| ShopSheet.dc.html | Shop sheet over the map |
| Wallet.dc.html | Wallet list |
| Card.dc.html | My card sheet (QR, code, Add to Apple Wallet) |
| Inbox.dc.html | Activity / notifications |
| Join.dc.html | No-app join from the counter QR (web) |
| Counter.dc.html | Staff counter, member found |
| Dashboard.dc.html | Merchant dashboard home (web) |
