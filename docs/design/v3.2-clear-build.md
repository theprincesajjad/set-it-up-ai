## 1. Switching theme (landed)

| Where | What |
| --- | --- |
| `<html>` | `data-theme-style="clear" data-theme="light"` by default (root layout). Clear dark: `data-theme="dark"`. Warm: `data-theme-style="warm"` and no `data-theme` (Warm follows the device, unchanged). |
| Before paint | Root `<head>` script (`themeInitScript`, `apps/web/src/lib/theme.ts`): on `/m/<id>` and `/door/<id>` it reads cookie `ll-theme-<id>` (`clear` \| `clear-dark` \| `warm`); anywhere else Clear light. |
| Per shop | `<ThemeStyle style dark merchantId>` (`components/ui/ThemeStyle.tsx`) in `m/[merchantId]/layout.tsx` and `door/[merchantId]/layout.tsx`: an inline script with the shop's real setting, the same attributes in a layout effect on client navigation, and the cookie refresh. Customer pages for a shop: `app/(pass)/shops/[slug]/layout.tsx` wraps them in `<ThemeStyle style={shop.themeStyle}>` (light only). Customer pages without a shop are Clear light. |
| QA override | `?theme=clear` \| `clear-dark` \| `warm` on any URL, one page load, not saved. Use it for screenshots. |
| In React | `const { clear, style, dark } = useThemeStyle()` (Clear when no provider). Prefer CSS variants over branching. |
| In CSS / Tailwind | `clear:` and `warm:` variants (`clear:rounded-r6`, `warm:rounded-card`), `dark:` (never fires from the OS under Clear), `rt:` (prefers-reduced-transparency). |
| Setting | `merchants.theme_style` text (`clear` default) and `merchants.theme_dark` boolean (false), migration `0031_clear_theme.sql`. API: `PATCH /v1/merchants/:id { themeStyle: "clear" \| "warm", themeDark: boolean }` (manager+), returned on `MerchantProfile` and on `MerchantBriefDto.themeStyle` (customer endpoints that serialise a full merchant row). Owner UI: Settings > Appearance (segmented Clear / Warm, dark mode switch shown only for Clear). i18n `settings.appearance.*` in en/hi/ur/pa. |

## 2. Tokens (landed): `packages/design-tokens`

Source `src/clear.ts`; emitted by `css.ts` into `css/tokens.css` under `:root[data-theme-style="clear"]` (light) and `:root[data-theme-style="clear"][data-theme="dark"]` (graphite). Warm's blocks are byte-for-byte as before, plus new roles with opaque Warm equivalents so every Clear class resolves under Warm too.

**Every existing role** (`--background`, `--foreground`, `--card`, `--muted`, `--muted-foreground`, `--border`, `--input`, `--ring`, `--primary`, `--sidebar-*`, `--points*`, `--success*`, `--info*`, `--warning*`, `--tile-*`, `--trade*` ...) has a Clear value, so existing classes (`bg-card`, `text-muted-foreground` ...) re-skin with no markup change. Values are the mock's: canvas `#F2F2F7`, ink `#17171A`, cards white, hairline `#E5E5EA`, muted text `#54545A`, black primary, link `#0066CC`; dark: `#000` / `#1C1C1E` / `#2C2C30` / white primary / link `#4DA3FF`. Points have no colour in Clear (`--points` = ink).

**New roles** (Tailwind colour classes in brackets):

| CSS variable | Class | Use |

| `--link` | `text-link` | Links, the active phone tab label |

| `--ll-shadow-card` (Clear value) | `shadow-card` | Rev 5 card elevation |

**Trade accents in Clear**: `[data-trade="<vertical>"]` (set by the shell) gives `--trade`, `--trade-foreground`, `--trade-tint`, `--trade-nav`, `--chart-hi` per family; `--trade-alt` and `--trade-deep` equal `--trade` (no gradient). Light = the family accent; dark = lifted to L69 (café pinned to `#E0A57F`). Trade colour only on the active nav item, icon tiles and the chart's current bar.

**Radii** (`rounded-r1` 4 · `r2` 8 · `r3` 10 · `r4` 12 · `r5` 16 · `r6` 20 · `r7` 26 · `r8` 30 · `r9` 32). `rounded-card` is 20 in Clear (22 Warm), `rounded-sheet` 32 (28), `rounded-tile` 20.

**Type**: Inter with `font-optical-sizing: auto` (variable `opsz` axis loaded); `font-display` and `font-wordmark` are Inter under Clear (Fraunces / Bricolage under Warm). The existing text styles take the audit's sizes under Clear: `text-body` 13/20, `text-body-strong` 13/20 650, `text-meta` 12/16, `text-caption` 12/16, `text-headline` 14/20 650 (card title), `text-title` 17/24 (sheet name), `text-large-title` 26/32 700 (page title), `text-display-number` 36/40 650 (stat number). Hindi, Urdu and Punjabi keep the Noto fallbacks and the Urdu leading rules in `globals.css`.

**Contrast**: `test/clear.test.ts` checks every v3 pair in Clear light and dark, links, chips, toast, text on each glass fill over canvas and card, the reduced-transparency fills, and per trade family (light and dark): label on accent, glyph on card, canvas, tint and active nav.

**Mobile** (landed): `import { clearRoles, clearExtra, clearExtraSolid, clearGlass, clearGlassSolid, clearTradeColors, clearLayout, clear, THEME_STYLES, themeStyleOf } from "@ll/design-tokens"` (same as `warm`, `tradeColors`). `clearGlass[theme].blur` is a number (px) for `expo-blur` intensity mapping; fills are `rgba()` strings; `clearExtraSolid` / `clearGlassSolid` are opaque fallbacks; `clearLayout` holds the audit's spacing, radii and component sizes.

## 3. Glass utilities (landed): `css/theme.css`

| Utility | Mock class | Use |
| --- | --- | --- |
| `glass` / `glass-chrome` | `.lg` | Regular glass: toolbar, phone top capsules, glass circles |
| `glass-sheet` | `.lg.strong` | Sheets, phone tab bar, pass card, popovers |
| `glass-side` | `.side.lg.strong` | The floating sidebar |
| `glass-lite` | `.lg.lite` | Small glass buttons (Print QR kit, Filter, Sort, EN) |
| `glass-flat` | `[data-flat]` | Counter top bar and dock: blur only, no rim, no lens |
| `glass-lift` | `.lift` | Selected nav item / tab (lifted glass) |
| `glass-seg-on`, `seg-track` | `.seg span.on`, `.seg` | Segmented control |
| `card-clear` | `.card` | Flat card: white, r20, hairline as inset shadow, rev 5 elevation |
| `hairline-inset` | | Inset 1px border only |
| `divide-overlay`, `divide-overlay-inset` | `.li+.li::after` | Row dividers drawn over the row (no layout height); inset 16 on phones |
| `rule-top` | `.ch+.li::after` | One overlaid top rule (first row after a header) |
| `scroll-edge-top`, `scroll-edge-bottom` | `.sedge.t`, `.sedge.b` | Fixed blur strip behind chrome (84 / 120 tall); set `inset-inline` yourself |

Each glass utility draws the specular rim in `::before` (do not use `before:` on the same element). Reduced transparency (`prefers-reduced-transparency: reduce`, or `class="solid"` on `<html>`) swaps every glass role to opaque values, blur 0, no rim; the scroll-edge strips hide. `prefers-reduced-motion` is already global (transitions 1ms). Under Warm the glass roles are opaque Warm values.

**Refraction** (landing): `<LiquidGlassLens />` (mounted by the shell) adds the SVG displacement filter to every element with `data-lens` in Chromium only, behind feature detection, skipped under reduced transparency. Put `data-lens` on chrome you want lensed; never on the counter bars.

## 7. What screen teams should use

- Colours: the existing role classes; new roles from section 2. Never hex; `no-raw-colors` is an error.
- Glass only on chrome (section 3). Cards, rows, tables and charts are flat (`card-clear`, `SurfaceCard`).
- Trade colour only via `text-trade`, `bg-trade-tint`, `bg-chart-hi`.
- Sizes from the audit: `rounded-r1..r9`, the button scale via `Button` sizes, `CardHead` 56, `Row` 64 / 44, `PageGrid`.
- To check your screen: `?theme=clear`, `?theme=clear-dark`, `?theme=warm` on any URL; `?lang=ur` or the language menu for RTL.
- Under Warm your screen must still look like Warm: put Clear-only structure behind `clear:` classes or `useThemeStyle().clear`.
