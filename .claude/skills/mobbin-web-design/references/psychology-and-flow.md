# Psychology & flow — learned from Mobbin web

## Belief sequence (marketing)

Most strong Sites pages walk belief in this order. Reorder only when your
shortlist clearly shows a different category grammar (e.g. editorial content
sites lead with story, not CTA).

1. **Promise** (hero) — outcome + path
2. **Proof** — logos, counts, quotes (often immediately under hero)
3. **Mechanism** — features / how it works
4. **Offer** — pricing / plans
5. **Objections** — FAQ, comparisons
6. **Re-ask** — final CTA
7. **Orient** — footer

### First-viewport discipline

Unless category refs *and* brand require otherwise:

- Brand as hero-level signal
- One headline, one support, one CTA group
- One dominant visual
- No stat strip / schedule / address block competing in the fold

Proof can sit **at the fold edge** (logo bar) when refs do it without stealing
the composition.

## Checkout / subscribe spine (web apps)

Typical Mobbin web flow (verify per shortlist):

1. Plan context (what you get; trial framing)
2. Account / seat configuration
3. Address + tax awareness
4. Payment method + trust band
5. Review with sticky summary
6. Confirm → return to product (one-way door)

### Psychology at money steps

| Moment | Device |
|---|---|
| Entering billing | Rocket / launch metaphor optional; clarity > cute |
| Method select | Large selectable cards; brand marks inside fields |
| Invalid field | Inline error, keep values, disable submit |
| Summary | Itemize tax; shout honest “due today” |
| Confirm | Terms checkbox if refs use it; green/blue primary per brand |

## App-shell psychology

- **Upgrade badges** teach the ladder without dead-ending navigation
- **Welcome banners** on first home teach the primary create action
- **Empty states** are onboarding, not blank rectangles
- **Search in the shell** signals a large information space — only include if
  the product has enough destinations to justify it (refs will tell you)

## Ethical line

Use persuasion patterns that appear in reputable category winners.
Do not import dark patterns (hidden cancel, fake urgency timers, pre-checked
paid add-ons) just because one capture somewhere shows them.
